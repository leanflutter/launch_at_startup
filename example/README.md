# launch_at_startup_example

Demonstrates `launch_at_startup` through its 0.5.x compatible API
(`package:launch_at_startup/legacy.dart`).

The full native example — `LaunchAtLogin` with its identifier, display name,
program and arguments — is nativeapi's
[launch_at_login_example](https://github.com/libnativeapi/nativeapi-flutter/tree/main/examples/launch_at_login_example).
